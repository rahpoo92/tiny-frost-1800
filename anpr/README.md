# سامانه پلاک‌خوان هوشمند (ANPR ایرانی)

نرم‌افزار دسکتاپ برای خواندن خودکار پلاک خودروهای ایرانی از روی تصویر یک دوربین متصل به سیستم، تطبیق پلاک با یک «بانک پلاک» (افراد ثبت‌شده)، و ثبت دقیق ورود/خروج هر پلاک به همراه تاریخ و ساعت شمسی. برای مواردی مثل پارکینگ مطب/شرکت طراحی شده: مثلاً وقتی پلاک ثبت‌شده‌ی «دکتر فلانی» دیده شود، پیام «دکتر فلانی وارد شد» (و بار بعد «دکتر فلانی خارج شد») ثبت و نمایش داده می‌شود. پلاک‌های ناشناس هم ثبت می‌شوند، فقط بدون نام.

## این نرم‌افزار چطور کار می‌کند

پردازش تصویر کاملاً محلی و آفلاین انجام می‌شود (هیچ تصویری به سرویس بیرونی فرستاده نمی‌شود):

1. **تشخیص محل پلاک** در فریم دوربین (`anpr_app/vision/detector.py`) با پردازش تصویر کلاسیک (لبه‌یابی + گرادیان)، بدون نیاز به مدل هوش مصنوعی دانلودی.
2. **جداسازی کاراکترها** از روی برش پلاک (`segmenter.py`).
3. **بازشناسی هر کاراکتر** با تطبیق الگو (`classifier.py`) — رقم‌ها ارقام لاتین معمولی‌اند، حرف وسط پلاک هم از الفبای فارسی است.
4. **رأی‌گیری روی چند فریم پیاپی** (`reader.py`): به‌جای اعتماد به یک فریم، چند فریم متوالی از همان پلاک با هم مقایسه می‌شوند و نتیجه‌ی نهایی از رأی اکثریت به‌ازای هر کاراکتر ساخته می‌شود؛ این مهم‌ترین عامل دقت در یک ANPR واقعی روی ویدیوی زنده است.
5. **تطبیق با بانک پلاک** و **تشخیص ورود/خروج** (`core/access_control.py`) و ثبت در پایگاه‌داده SQLite.

## روی ویندوز، بدون خط فرمان

اگر سیستمی که قرار است این برنامه رویش نصب شود ویندوز است و نمی‌خواهید با خط فرمان کار کنید، دو فایل آماده هست:

### گزینه‌ی ۱: اجرای مستقیم با یک دابل‌کلیک (`Start.bat`)

یک‌بار [پایتون ۳.۱۱ یا بالاتر](https://www.python.org/downloads/) را نصب کنید (هنگام نصب تیک **Add python.exe to PATH** را بزنید). بعد کافی‌ست پوشه‌ی `anpr` را روی همان سیستم کپی کنید و **`Start.bat`** را دابل‌کلیک کنید:

- بار اول: خودش محیط برنامه را می‌سازد، بسته‌های لازم را نصب می‌کند (چند دقیقه طول می‌کشد)، فایل تنظیمات را می‌سازد و Notepad را باز می‌کند تا آدرس دوربین را وارد کنید.
- دفعات بعد: فقط چند ثانیه طول می‌کشد و مستقیم برنامه باز می‌شود.

### گزینه‌ی ۲: ساخت یک فایل exe مستقل (برای نصب روی چند سیستم بدون پایتون)

اگر می‌خواهید یک فایل exe تنها بسازید که بدون نیاز به نصب پایتون روی سیستم اصلیِ کنار دوربین اجرا شود، روی **یک سیستم ویندوزی** (فقط همان‌جا که فایل exe را می‌سازید نیاز به پایتون دارد) دستور زیر را بزنید:

```
build_windows_exe.bat
```

این کار چند دقیقه طول می‌کشد و در پوشه‌ی `dist`، دو فایل **`PlateReader.exe`** و **`config.example.yaml`** ساخته می‌شود. همین دو فایل را با هم روی سیستم کنار دوربین کپی کنید و `PlateReader.exe` را اجرا کنید — دیگر نیازی به پایتون یا هیچ نصب دیگری روی آن سیستم نیست.

> چرا خودِ فایل exe را این‌جا برایتان آماده نکرده‌ام؟ چون این نشست روی یک سرور لینوکسی اجرا می‌شود و فایل exeِ ویندوز باید روی خودِ ویندوز ساخته شود؛ `build_windows_exe.bat` دقیقاً همان یک دستور را برایتان اجرا می‌کند.

## نصب (روش دستی — لینوکس/مک، یا اگر خط فرمان راحت‌تان است)

نیازمند Python 3.11 یا بالاتر.

```bash
cd anpr
python3 -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

## راه‌اندازی اولیه

1. فایل تنظیمات را از روی نمونه بسازید (یا فقط یک‌بار `python run.py` را اجرا کنید؛ خودش می‌سازد):
   ```bash
   cp config.example.yaml config.yaml
   ```
2. در `config.yaml`، مقدار `source` را با دوربین خودتان تنظیم کنید:
   - وبکم متصل به همین سیستم: عدد `0` یا `1`
   - دوربین تحت شبکه/مداربسته: آدرس RTSP، مثل `rtsp://user:pass@192.168.1.10:554/stream1`
3. اجرا:
   ```bash
   python run.py
   ```

پنجره‌ی اصلی، تصویر زنده‌ی دوربین را با کادر دور پلاکِ شناسایی‌شده نشان می‌دهد و رویدادهای ورود/خروج در ستون کناری ظاهر می‌شوند. از دکمه‌ی «مدیریت افراد و پلاک‌ها» برای افزودن افراد (نام، سمت مثل «دکتر») و پلاک‌های آن‌ها استفاده کنید؛ از دکمه‌ی «گزارش کامل ورود و خروج» برای دیدن/فیلتر کردن/خروجی CSV گرفتن از کل تاریخچه.

### دو دوربین جدا برای ورود و خروج (اختیاری)

اگر فقط یک دوربین دارید، حالت پیش‌فرض `role: toggle` است: نرم‌افزار خودش با دیدن دوباره‌ی یک پلاک، جهت آن را نسبت به آخرین بار برعکس می‌کند (بار اول = ورود، بار بعد = خروج، و به همین ترتیب). اگر دو دوربین جدا دارید، در `config.yaml` برای هرکدام `role: entry` یا `role: exit` بگذارید تا جهت بر اساس همان دوربین ثابت باشد، نه حدس زدن.

## دقتِ بازشناسی و اینکه چطور آن را بالا ببرید (مهم‌ترین بخش)

نرم‌افزار از همان لحظه‌ی نصب، بدون هیچ آموزشی، با یک مجموعه الگوی اولیه (ساخته‌شده از فونت‌های سیستم برای ارقام و حروف فارسی) کار می‌کند. این الگوهای اولیه دقتِ معقولی می‌دهند ولی طبیعتاً با فونت واقعی پلاک ایران و زاویه/نور دوربین شما یکی نیستند — در آزمایش روی یک عکس واقعی پلاک، الگوهای اولیه ۶ از ۸ کاراکتر را درست تشخیص دادند.

**راه رسیدن به دقت بالا، ابزار ثبت نمونه (enrollment) است:**

```bash
python tools/enroll.py path/to/photo.jpg
# یا یک پوشه پر از عکس:
python tools/enroll.py path/to/folder/
```

این ابزار پلاک را در عکس پیدا می‌کند، هر کاراکتر را تک‌تک نشان می‌دهد (همراه با حدس فعلی نرم‌افزار)، و برچسب درست را از شما می‌گیرد. همین چند نمونه‌ی واقعی برای هر کاراکتر مشکل‌دار کافی است: در همان آزمایش، بعد از ثبت فقط ۲ نمونه‌ی واقعی برای رقمی که اشتباه تشخیص داده می‌شد، هر ۸ کاراکتر همان پلاک با امتیاز بالا (بالای ۰.۸۵) درست شناسایی شد.

توصیه: از چند عکس/فریم واقعیِ گرفته‌شده با همان دوربین و در همان شرایط نوری که قرار است نرم‌افزار در آن کار کند استفاده کنید، و برای هر کاراکتری که در نوار وضعیت یا در گزارش‌ها می‌بینید درست تشخیص داده نمی‌شود، چند نمونه بیشتر ثبت کنید. نیازی به قطع نرم‌افزار نیست؛ کافی است بعد از ثبت نمونه‌ها، برنامه‌ی اصلی را یک‌بار ببندید و دوباره باز کنید تا الگوهای جدید را بخواند.

نوار پایین پنجره‌ی اصلی همیشه می‌گوید چند کاراکتر از کل الفبا و ارقام الگو دارند.

### چرا آستانه‌ی اطمینان مهم است

نرم‌افزار عمداً طوری تنظیم شده که **به‌جای ثبت یک پلاک اشتباه، هیچ‌چیز ثبت نکند** وقتی مطمئن نیست (پارامترهای `min_char_confidence` و `min_plate_confidence` در `config.yaml`). اگر می‌بینید پلاکی اصلاً ثبت نمی‌شود، معمولاً یعنی یکی از کاراکترهایش هنوز الگوی کافی ندارد — دقیقاً همان‌جاست که باید نمونه ثبت کنید.

## ساختار پروژه

```
anpr/
  run.py                     نقطه‌ی شروع برنامه
  Start.bat                  اجرای مستقیم روی ویندوز، بدون خط فرمان (نصب/به‌روزرسانی خودکار)
  build_windows_exe.bat      ساخت یک PlateReader.exe مستقل برای نصب روی سیستم‌های دیگر
  config.example.yaml        نمونه‌ی تنظیمات (config.yaml از روی این ساخته می‌شود)
  anpr_app/
    config.py                خواندن تنظیمات
    jalali.py                تبدیل تاریخ میلادی/شمسی
    database/db.py           پایگاه‌داده SQLite: افراد، پلاک‌ها، تاریخچه‌ی ورود/خروج
    vision/                  تشخیص پلاک، جداسازی و بازشناسی کاراکتر، رأی‌گیری چندفریمی
    core/                    تطبیق پلاک با بانک اطلاعاتی + تشخیص ورود/خروج + رشته‌ی دوربین (QThread)
    gui/                     پنجره‌ی اصلی، مدیریت افراد/پلاک‌ها، گزارش‌ها (PySide6)
  tools/enroll.py            ابزار ثبت نمونه‌ی واقعی کاراکتر برای افزایش دقت
  tests/                     آزمون‌های خودکار (pytest)
```

## اجرای آزمون‌ها (برای توسعه‌دهنده)

```bash
pip install -r requirements-dev.txt
pytest
```

## محدودیت‌های شناخته‌شده

- تشخیص محل پلاک با پردازش تصویر کلاسیک انجام می‌شود، نه یک مدل یادگیری عمیق؛ روی عکس/ویدیوی واقعی (نویز و بلور طبیعی دوربین) به‌خوبی کار می‌کند، اما پلاک‌های بسیار کثیف، بسیار کج، یا نورپردازی شدید ممکن است نیاز به تنظیم پارامترهای `detector.py` داشته باشند.
- فهرست حروف پلاک در `anpr_app/vision/plate_letters.py` رایج‌ترین حروف را پوشش می‌دهد؛ اگر پلاکی با حرف دیگری دیدید، همان‌جا یک ردیف به دیکشنری `LETTERS` اضافه کنید.
- برای دقت بالا، ثبت چند نمونه‌ی واقعی با `tools/enroll.py` عملاً ضروری است — بخش «دقتِ بازشناسی» بالا را ببینید.
